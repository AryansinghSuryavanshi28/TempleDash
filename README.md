# 🏛️ Temple Dash — Endless Runner Game

**Run. Jump. Dodge. Collect. Survive!** 🪙

Temple Dash is a browser-based endless runner game inspired by classic adventure-running games like Temple Run. Navigate through a jungle temple, avoid dangerous obstacles, collect golden coins, and challenge yourself to achieve a high score.

Built using **HTML, CSS, and JavaScript**, the game runs directly in your browser without requiring any additional libraries or installations.

## 🎮 Game Preview

Explore an ancient jungle, race down a stone path, and test your reflexes as the game gets faster!

## ✨ Features

- 🏃 **Endless Running Gameplay** — Keep running and try to beat your highest score.
- ↔️ **Three-Lane Movement** — Switch between three lanes to avoid obstacles.
- 🦘 **Jump Mechanic** — Jump over rocks and logs to stay alive.
- 🪙 **Coin Collection** — Collect golden coins to earn extra points.
- 📈 **Dynamic Difficulty** — The running speed increases as you progress.
- 📱 **Responsive Design** — Play on desktop and mobile devices.
- ⚡ **Lightweight and Fast** — Runs directly in your web browser.
- 🎨 **Jungle-Themed Graphics** — Enjoy a colorful environment with a temple, jungle, and stone running path.
- 🧩 **Beginner-Friendly Code** — Easy to understand, modify, and extend.

## 🕹️ How to Play

| Action | Controls |
|---|---|
| Move left | `←` or `A` |
| Move right | `→` or `D` |
| Jump | `↑` or `Spacebar` |
| Start or restart | Click the game button |

### Objective

1. Start your adventure.
2. Dodge obstacles by switching lanes.
3. Jump over obstacles when necessary.
4. Collect as many coins as possible.
5. Survive longer and aim for a higher score!

## 🛠️ Built With

- **HTML5** — Structures the game interface.
- **CSS3** — Creates the layout, jungle environment, road, animations, and responsive controls.
- **JavaScript** — Implements player movement, jumping, obstacle spawning, collision detection, coin collection, and scoring.

No external frameworks or libraries are required.

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser such as Google Chrome, Firefox, or Microsoft Edge.

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual repository URL.

**2. Open the project folder**

```bash
cd TempleDash
```

**3. Launch the game**

Open `index.html` in your browser.

That's it! No build tools or package installation needed.

## 🌐 Deployment

You can host Temple Dash for free using GitHub Pages.

1. Push your project files to a GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Choose your main branch and the root folder.
5. Save the settings and wait for deployment.

GitHub will provide a public URL where people can play your game.
